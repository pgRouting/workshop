5. Datos para los Objetivos de Desarrollo Sostenible¶

To be able to use pgRouting, data has to be imported into a database. This chapter will use osm2pgrouting to get the data from OpenStreetMap (OSM). This data will be used for exercises in further chapters.

pgRouting is an extension which requires:

  • Versión PostgreSQL compatible

  • Versión PostGIS compatible

These requirements are met on OSGeoLive. When the required software is installed, open a terminal window by pressing ctrl-alt-t and follow the instructions. Information about installing OSGeoLive can be found in OSGeoLive Installation of this workshop.

Nota

Si no está pgRouting instalado. Se puede encontrar el procedimiento de instalación en este enlace

5.1.1. Crear base de datos de Mumbai compatible con pgRouting¶

Utilice el siguiente comando para crear la base de datos mumbai

createdb mumbai

Para conectarse a la base de datos, haga lo siguiente

psql mumbai

After connecting to the database, the first step is to create EXTENSION to enable pgRouting and PostGIS in the database. Then add the SCHEMA that are needed.

1-- add pgRouting extension
2CREATE EXTENSION pgrouting CASCADE;
3
4-- creating schemas for data
5CREATE SCHEMA roads;
6CREATE SCHEMA buildings;
7CREATE EXTENSION hstore;

5.1.2. Obtenga los datos de Mumbai¶

El taller pgRouting hará uso de los datos de OpenStreetMap de un área en la ciudad de Mumbai. Las instrucciones para descargar los datos se dan a continuación.

Descarga de datos de Mumbai desde OSGeo

El siguiente comando se utiliza para descargar la instantánea de los datos del área de Mumbai utilizados en este taller, utilizando el servicio de descarga de OSGeo.

Nota

Los datos de Mumbai para este taller depende de ésta instantanea.

1wget -N --progress=dot:mega "https://download.osgeo.org/pgrouting/workshops/mumbai.osm.bz2"
2bunzip2 -f "mumbai.osm.bz2"

The following command was used in June 2021 to download the OpenStreetMap data of the area in Mumbai, India.

1CITY="mumbai"
2BBOX="72.8263,19.1021,72.8379,19.1166"
3wget --progress=dot:mega -O "$CITY.osm" "http://www.overpass-api.de/api/xapi?*[bbox=][@meta]"

5.1.6. Compatibility with older osm2pgrouting versions (Mumbai)¶

Check the installed version:

osm2pgrouting --version

If you are using version 2.x, the column names differ from those used in this workshop:

  • gid instead of id

  • the_geom instead of geom

Run the following script to rename them:

ALTER TABLE roads.ways RENAME COLUMN gid TO id;
ALTER TABLE roads.ways RENAME COLUMN the_geom TO geom;
ALTER TABLE buildings.ways RENAME COLUMN gid TO id;
ALTER TABLE buildings.ways RENAME COLUMN the_geom TO geom;

5.1.7. Verify the data (Mumbai)¶

Para conectarse a la base de datos, escribir lo siguiente en el terminal.

psql mumbai

The following command was used in June 2021 to download the OpenStreetMap data of the area in Munshigang, Bangladesh.

1CITY="bangladesh"

4
5osmconvert --drop-author --drop-version bangladesh.osm -o=bangladesh_pass1.osm
6osmfilter bangladesh_pass1.osm -o=bangladesh.osm --drop="highway= building="
