1.1. データベースの準備¶

pgRouting は拡張機能としてインストールされます。以下が必要となります:

  • PostgreSQL

  • PostGIS

これらの要件は OSGeoLive では満たされています。必要なソフトウェアがインストールされたら、ctrl-alt-t を押してターミナルウィンドウを開き、手順に従ってください。

OSGeoLive のインストールに関する情報は OSGeoLive のインストール にあります。

1.1.1. pgRouting 互換データベースの作成¶

ワークショップで使用する city_routing データベースを作成します。

createdb city_routing

データベースへの接続

psql city_routing

pgRouting とその要件をインストールします。(オプションで、使用しているバージョンを確認します)

CREATE EXTENSION pgrouting CASCADE;

-- Inspect the pgRouting installation
\dx+ pgrouting

-- View pgRouting version
SELECT pgr_full_version();

データベースの終了

\q

1.2. ワークショップデータの取得¶

このワークショップでは Hiroshima 市のデータを使用します。これは 2026年6月時点のスナップショットです。

1.2.1. データの取得¶

1.2.1.1. pgRouting のダウンロードサイトからデータをダウンロード¶

全く同じデータが OSGeoLive のダウンロードページにあります。

CITY="HIROSHIMA_JP"
wget -N --progress=dot:mega "https://download.osgeo.org/pgrouting/workshops/HIROSHIMA_JP.osm.bz2"
bunzip2 -f "HIROSHIMA_JP.osm.bz2"

1.2.1.2. オプション 3) Overpass XAPI を使用してダウンロード¶

以下では、同じエリアの最新の OSM データをダウンロードします。このデータをワークショップで使用すると、2026年6月以降の変更により、結果に差異が生じる可能性があります。

CITY="HIROSHIMA_JP"
BBOX="132.439,34.33,132.4782,34.412"
wget --progress=dot:mega -O "$CITY.osm" "http://www.overpass-api.de/api/xapi?*[bbox=\$\{BBOX\}][@meta]"

OpenStreetMap データのダウンロード方法に関する詳細は こちら を参照してください。

もっと広いエリアのデータを Geofabrik のダウンロードサービスから取得するという方法もあります。

1.3. データベースへのデータのアップロード¶

次のステップでは osm2pgrouting コンバータを実行します。これはデータをデータベースに挿入し、pgRouting で「すぐに使える」状態にするコマンドラインツールです。osm2pgrouting に関する詳細は 付録: osm2pgrouting インポートツール にあります。

このステップでは:

  • osm2pgrouting の既定の mapconfig.xml 設定ファイルを使用します

  • ~/Desktop/workshop/HIROSHIMA_JP.osm のデータを使用します

  • city_routing データベースを使用します

ターミナルウィンドウ ctrl-alt-t から実行します。

1.3.1. osm2pgrouting コンバータの実行¶

/usr/bin/osm2pgrouting \
    -f "HIROSHIMA_JP.osm" \
    -c "/usr/share/osm2pgrouting/mapconfig.xml" \
    -d city_routing \
    -U user \
    -W user \
    --clean

注釈

osm2pgrouting のバージョンによっては -W password が必要です

1.3.2. 古いバージョンの osm2pgrouting との互換性¶

インストールされているバージョンを確認します:

osm2pgrouting --version

バージョン 2.x を使用している場合、列名はこのワークショップで使用されているものとは異なります:

  • id ではなく gid

  • geom ではなく the_geom

名前を変更するには、以下のスクリプトを実行します:

ALTER TABLE ways RENAME COLUMN gid TO id;
ALTER TABLE ways RENAME COLUMN the_geom TO geom;
