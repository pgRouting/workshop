1. QGIS の使用¶

他の種類の関数は pl/pgsql にあります。アプリケーションの要件が複雑になるにつれて、あらかじめ定義した関数を使うことが必要になります。

1.1. QGIS のセットアップ¶

グラフには set of edges と set of vertices が関連付けられています。osm2pgrouting は、ways テーブルに関連付けられた ways_vertices_pgr テーブルを提供します。vehicle_net や small_net のように edges の部分集合を使う場合は、たとえば緯度経度の位置に最も近い頂点を特定するために、それぞれに対応する頂点の集合を使う必要があります。

  1. Geospatial ‣ Desktop GIS ‣ QGIS から QGIS を起動し、メニューバーから Project ‣ Open を選択します。

    注釈

    QGIS の場所は環境によって異なる場合があります。

    このワークショップの手順は QGIS 2.14 Essen を前提としています

  2. ブラウザパネルを閉じます

  3. Add postGIS layer をクリックして、PostGIS が有効な PostgreSQL データベースに接続します

  4. New をクリックして、新しい接続を作成します

  5. 情報を入力し、接続をテストします

    名前:

    city_routing

    ホスト:

    localhost

    ポート:

    5432

    データベース:

    city_routing

    ユーザ名:

    user

    パスワード:

    user

  6. QGIS にログイン名とパスワードを記憶させます

1.2. PostGIS レイヤの追加¶

Connect をクリックすると、データベース内のテーブルとビューの一覧が表示されます。

一意の値を持つ列を選択する必要があります:

  • ルート検索ビューでは seq

  • データビューでは gid

1.3. ルート検索レイヤの書式設定¶

  1. ルート検索ビューを選び、Right click ‣ Zoom to Layer を実行します

  2. Right click ‣ Properties

  3. Style ‣ Color

  4. Style ‣ + ‣ Symbol Layer Type ‣ Marker line

  5. Apply ‣ Close

1.4. 書式のコピーと貼り付け¶

  1. 書式を設定したレイヤを選び、Right click ‣ Styles ‣ Copy Styles を実行します

  2. 別のレイヤを選び、Right click ‣ Styles ‣ Paste Styles を実行します

1.5. プロジェクトの保存¶

  1. Project ‣ Save As ...

  2. User ‣ Desktop ‣ workshop に移動し、pgrouting-Bucharest-Example という名前で保存します
