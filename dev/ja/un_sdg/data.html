5. 持続可能な開発目標のためのデータ¶

pgRouting を利用するためには、データがデータベースにインポートされている必要があります。この章では osm2pgrouting を使用して OpenStreetMap (OSM) からデータを取得します。このデータは以降の章の演習で使用します。

pgRouting は拡張機能であり、以下が必要となります:

  • サポートされている PostgreSQL のバージョン

  • サポートされている PostGIS のバージョン

これらの要件は OSGeoLive では満たされています。必要なソフトウェアがインストールされたら、ctrl-alt-t を押してターミナルウィンドウを開き、手順に従ってください。OSGeoLive のインストールに関する情報は、このワークショップの OSGeoLive のインストール にあります。

注釈

pgRouting がインストールされていない場合は、この リンク にインストール手順があります。

インストールするデータベースは、取り組む UN SDG の章によって異なります:

5.1.1. pgRouting 互換の Mumbai データベースの作成¶

以下のコマンドを使用して mumbai データベースを作成します

createdb mumbai

データベースに接続するには以下を実行します

psql mumbai

データベースに接続したら、最初の手順は、そのデータベースで pgRouting と PostGIS を有効にするために EXTENSION を作成することです。次に、必要な SCHEMA を追加します。

1-- add pgRouting extension
2CREATE EXTENSION pgrouting CASCADE;
3
4-- creating schemas for data
5CREATE SCHEMA roads;
6CREATE SCHEMA buildings;
7CREATE EXTENSION hstore;

5.1.2. Mumbai データの取得¶

pgRouting ワークショップでは、Mumbai 市内のあるエリアの OpenStreetMap データを使用します。データをダウンロードする手順は以下のとおりです。

OSGeo から Mumbai データをダウンロードする

以下のコマンドは、OSGeo のダウンロードサービスを使用して、このワークショップで使用する Mumbai エリアのデータのスナップショットをダウンロードするためのものです。

注釈

このワークショップの Mumbai データは、この スナップショット に依存しています。

1wget -N --progress=dot:mega "https://download.osgeo.org/pgrouting/workshops/mumbai.osm.bz2"
2bunzip2 -f "mumbai.osm.bz2"

以下のコマンドは、インドの Mumbai にあるエリアの OpenStreetMap データをダウンロードするために 2021年6月に使用したものです。

1CITY="mumbai"
2BBOX="72.8263,19.1021,72.8379,19.1166"
3wget --progress=dot:mega -O "$CITY.osm" "http://www.overpass-api.de/api/xapi?*[bbox=][@meta]"

5.1.6. 古いバージョンの osm2pgrouting との互換性 (Mumbai)¶

インストールされているバージョンを確認します:

osm2pgrouting --version

バージョン 2.x を使用している場合、列名はこのワークショップで使用されているものとは異なります:

  • id ではなく gid

  • geom ではなく the_geom

名前を変更するには、以下のスクリプトを実行します:

ALTER TABLE roads.ways RENAME COLUMN gid TO id;
ALTER TABLE roads.ways RENAME COLUMN the_geom TO geom;
ALTER TABLE buildings.ways RENAME COLUMN gid TO id;
ALTER TABLE buildings.ways RENAME COLUMN the_geom TO geom;
