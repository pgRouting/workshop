1. Förbereda data¶

För att kunna använda pgRouting måste data importeras till en databas.

1.1. Förbereda databasen¶

pgRouting installeras som tillägg. Detta kräver:

  • PostgreSQL

  • PostGIS

Dessa krav uppfylls på OSGeoLive. När den programvara som krävs är installerad, öppna ett terminalfönster genom att trycka på ctrl-alt-t och följ instruktionerna.

Information about installing OSGeoLive can be found on OSGeoLive Installation.

1.1.1. Skapa en databas som är kompatibel med pgRouting¶

Create city_routing database that will be used on the workshop.

createdb city_routing

Connect to the database

psql city_routing

Install pgRouting and its requirements. (otpionally check the version that is being used)

CREATE EXTENSION pgrouting CASCADE;

-- Inspect the pgRouting installation
\dx+ pgrouting

-- View pgRouting version
SELECT pgr_full_version();

Exit the database

\q

1.2. Hämta verkstadsdata¶

This workshop will use the Hiroshima city data and is a snapshot of Jun 2026.

1.2.1. Get the data¶

1.2.1.1. Download data form pgRouting download¶

Exakt samma data finns på nedladdningssidan för OSGeoLive.

CITY="HIROSHIMA_JP"
wget -N --progress=dot:mega "https://download.osgeo.org/pgrouting/workshops/HIROSHIMA_JP.osm.bz2"
bunzip2 -f "HIROSHIMA_JP.osm.bz2"

1.2.1.2. Alternativ 3) Ladda ner med hjälp av Overpass XAPI¶

The following downloads the latest OSM data on using the same area. Using this data in the workshop can generate variations in the results, due to changes since Jun 2026.

CITY="HIROSHIMA_JP"
BBOX="132.439,34.33,132.4782,34.412"
wget --progress=dot:mega -O "$CITY.osm" "http://www.overpass-api.de/api/xapi?*[bbox=\$\{BBOX\}][@meta]"

More information about how to download OpenStreetMap data can be found here.

Ett alternativ för mycket stora områden är att använda nedladdningstjänsterna från Geofabrik.

1.3. Ladda upp data till databasen¶

Nästa steg är att köra osm2pgrouting converter, som är ett kommandoradsverktyg som infogar data i databasen, ”redo” att användas med pgRouting. Ytterligare information om osm2pgrouting finns i Bilaga: Importverktyg för osm2pgrouting

För detta steg:

  • osm2pgroutings standardkonfigurationsfil mapconfig.xml används

  • and the ~/Desktop/workshop/HIROSHIMA_JP.osm data

  • med databasen city_routing

Från ett terminalfönster ctrl-alt-t.

1.3.1. Kör konverteraren osm2pgrouting¶

/usr/bin/osm2pgrouting \
    -f "HIROSHIMA_JP.osm" \
    -c "/usr/share/osm2pgrouting/mapconfig.xml" \
    -d city_routing \
    -U user \
    -W user \
    --clean

1.3.2. Compatibility with older osm2pgrouting versions¶

Check the installed version:

osm2pgrouting --version

If you are using version 2.x, the column names differ from those used in this workshop:

  • gid instead of id

  • the_geom instead of geom

Run the following script to rename them:

ALTER TABLE ways RENAME COLUMN gid TO id;
ALTER TABLE ways RENAME COLUMN the_geom TO geom;
